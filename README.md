# Veda Technology – Task 17: Random Password Generator 🔐

## 📌 Project Overview

A responsive Random Password Generator developed using HTML5, CSS3, and JavaScript as part of the Veda Technology Web Development Internship.

This application generates random passwords based on the selected password length and character types, helping users explore password-generation concepts.

## ✨ Features

- 🔢 Adjustable password length from 8 to 64 characters
- 🔠 Uppercase letters (A–Z)
- 🔡 Lowercase letters (a–z)
- 🔢 Numbers (0–9)
- 🔣 Special symbols
- 🎲 Random password generation using the Web Crypto API
- 📋 Copy-to-clipboard functionality
- ⚠️ Validation when no character type is selected
- 📱 Responsive design for desktop and mobile devices
- 🎨 Modern interface with gradient styling

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Web Crypto API

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open the folder using the Live Server extension, or run `index.html` in a modern browser.
4. Select your desired password length.
5. Choose one or more character types.
6. Click **Generate Password**.
7. Click **Copy** to copy the generated password.

**Note:** The Web Crypto API and clipboard functionality require a supported browser and secure context, such as HTTPS or localhost.
