# Veda Technology – Task 17: Random Password Generator

## Project Overview

A responsive Random Password Generator developed using HTML5, CSS3, and JavaScript as part of the Veda Technology Web Development Internship.

## Features

- Adjustable password length from 8 to 64 characters
- Uppercase and lowercase character options
- Number and symbol options
- Generates a password using selected character types
- Copy-to-clipboard functionality
- Validation when no character type is selected
- Responsive design for mobile and desktop
- Uses the browser's Web Crypto API for random selection

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Web Crypto API

## Project Structure

- `index.html` – Page structure
- `style.css` – Design and responsive styling
- `script.js` – Password generation and copy functionality
- `README.md` – Project documentation

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server or a modern browser.
4. Choose the password length and character types.
5. Click **Generate Password**.
6. Click **Copy** to copy the generated password.

Note: Clipboard access and the Web Crypto API work in supported secure contexts, such as HTTPS or localhost.
